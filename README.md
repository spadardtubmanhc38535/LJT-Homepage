# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate in the HKUST NLP Group at the Hong Kong University of Science and Technology.

The site is built with [Jekyll](https://jekyllrb.com) and is a fork of the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, which itself is a fork of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme.

## Contents

- `_pages/about.md` - the home / about page (personal details, academic background, research experience, publications, skills, honors and contact information)
- `_pages/publications.html` - the publications listing page
- `_publications/` - one Markdown file per publication
- `_config.yml` - site-wide configuration and sidebar profile information
- `_data/navigation.yml` - the site navigation menu
